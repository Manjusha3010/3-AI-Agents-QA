Test Orchestrator

Full-stack web app: pull user stories from Jira, generate AI test plans and structured test cases, then export Playwright or Selenium automation code — one sidebar, end-to-end.

How the app flows

React UI talks to FastAPI; FastAPI calls Jira and your chosen LLM (Groq, Gemini, or Ollama).

What it does

  1. Connect Jira & LLM Settings for Groq/Gemini/Ollama; Jira URL + API token — or load sample stories without Jira.
  2. Generate test plan Pick a story → AI writes a markdown plan you can copy or extend.
  3. Create test cases From the plan → structured cases with steps, priority, status — edit in Test Case Creator.
  4. Dashboard & automation Filter cases on the dashboard; Code Generator outputs Playwright (JS/Python) or Selenium (Python).

Quick setup

Local (full features)

  1. Install Node.js + Python 3.11+
  2. Open Test Orchestrator → run START.bat
  3. Browser: http://127.0.0.1:8000 — keep the server window open
  4. Settings → LLM key → Jira (or sample stories) → generate plan & cases

Vercel UI only

  1. Use Open Live App above for the React frontend
  2. For API calls from Vercel, host server/ on Railway/Render and set VITE_API_URL

Important note

Vercel hosts the frontend build. FastAPI must run locally (START.bat) or on a Python host for Jira/LLM generation. API keys stay in your browser (localStorage) for demo use.
