What it does

  1. Ingest your documents Upload via form → split → embed with Mistral → save to Qdrant collection Advance_RAG.
  2. Ask questions in chat Chat trigger sends your message to the AI Agent (with short-term memory).
  3. Retrieve and re-rank Agent calls Qdrant as a tool; Cohere reranker picks the most relevant chunks.
  4. Get a grounded answer Groq composes the reply from re-ranked context — ideal for test plans, SOPs, and BRDs.

Real answers depend on the documents you ingest and your connected API keys.

Quick setup

  1. Open n8n → Import → AdvanceRAG.json
  2. Create Qdrant collection Advance_RAG
  3. Add credentials: Qdrant, Mistral, Cohere, Groq on each node
  4. Enable Ingestion nodes if disabled → activate → upload a file via form URL
  5. Use When chat message received → ask questions after ingestion completes

Important note

This page is documentation on Vercel. The workflow runs in n8n (cloud or self-hosted), not on Vercel. Import the JSON and connect your own API keys to use it live.
